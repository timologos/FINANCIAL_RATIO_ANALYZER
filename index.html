Financial Ratio Analyzer

Enter a company’s figures for the current year, and optionally a prior year, to get ratios with change arrows, a DuPont breakdown and an Altman Z-score. Use any currency, but keep it consistent.

CurrentPrior (optional)

Benchmarks are general rules of thumb. Healthy ranges differ a lot by industry, so compare against peers in the same sector. The Z-score uses the Z′ model for private manufacturers with book equity, so treat it as a rough signal for other sectors. This is an educational tool, not financial advice.
